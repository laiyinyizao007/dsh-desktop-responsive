# 卸载时还原宿主自己写的样式值

- 状态：已接受
- 日期：2026-11-03
- 相关提交：`4870762`（插件初版）

## 背景

Harness 的三栏外壳是一个 CSS Grid，网格轨道是 React 写的。插件在手机宽度下必须改写它——展开的侧栏要变成浮层抽屉，中间列要拿回全部宽度。

## 备选方案

1. 卸载时不还原，靠宿主重新渲染覆盖。
2. 卸载时把插件写的值清空（`element.style.gridTemplateColumns = ''`）。
3. 卸载时把宿主原来写的值原样写回去。

## 取舍理由

方案 1 不可靠：宿主不一定重渲染被插件动过的那个节点，用户看到的可能是残留。

方案 2 会抹掉宿主的值。React 只在它自己认为值变了的时候重写样式，插件把内联样式清空之后，React 并不认为发生了任何变化，于是宿主的网格再也回不来——宿主从此变成一台列。

方案 3 要求插件在改写之前记住原值，并在卸载时写回。代价是插件要负责记住自己动过什么。

## 影响范围

`client.js` 的 `syncGrid()` 负责改写与还原；样式统一挂在 `data-dshr-*` 属性与一个 `dsh-desktop-responsive` 样式键下，卸载时按这个键整体移除，并把记住的原值写回。

## 验证方式

`test/responsive-layout-client.test.mjs` 中"卸载之后宿主恢复原样"一类的用例覆盖该行为。

## 回滚策略

不适用。
